# Основы проектирования системы

## Функциональные требования

- публикация постов из путешествий:
  - фотографии
  - короткое описание
  - привязка к месту путешествия
- оценка и комментарии постов других путешественников
- подписка на других путешественников
- просмотр активности пользователей, на которых подписан
- поиск популярных мест для путешествий (наибольшее количество оценок)
- просмотр постов по конкретному месту
- просмотр ленты:
  - общая лента пользователей
  - лента подписок (reverse chronological order)
- доступ через:
  - мобильные устройства
  - браузер

---

## Нефункциональные требования

- DAU через год: **10 000 000**
- рост аудитории: линейный, далее после года продолжается рост
- география: **СНГ**
- доступность: **высокая (99.999%)**
- UX: быстрый и удобный на mobile + web (см. SLA)
